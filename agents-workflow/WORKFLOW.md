# Follow the Figma requirement

Read [the request](REQUEST.md) first. Each step below connects to actual selected instructions rather than replacing them with a new universal method.

| Step | Agent responsibility | Instructions to inspect | Output to the next step |
|---|---|---|---|
| 1. Receive and frame | The receiving agent reads project context, scope and existing components | [Working rules](Javier/WORKING_WITH_JAVIER.md), [encargar](skills/encargar/SKILL.md) | A bounded assignment with sources, exclusions and evidence expectations |
| 2. Inspect and decide | DS Manager owns component identity, tokens, API and the comparison presented to Javier | [Role](Design/DS%20Manager/DS_MANAGER.md), [component method](Design/Design%20Systems/DS_GUIDE.md) | Approved scope and the affected roles/modes; open questions stay explicit |
| 3. Build or maintain | DS Manager or a scoped worker implements the approved component change | [construir-componente](skills/construir-componente/SKILL.md) | Component plus instance checks and documented limits |
| 4. Check language when needed | Naming checks public names, layers and properties against responsibility | [Role](Design/Naming%20Architect/NAMING_ARCHITECT.md), [naming canon](Design/Figma/NAMING_STRUCTURE_GUIDE.md) | Naming findings or a justified mapping; no independent token decision |
| 5. Document the component | File Architect builds and places the requested documentation; DS Manager owns its technical meaning | [Role](Design/File%20Architect/FILE_ARCHITECT.md), [file method](Design/Figma/FILE_ARCHITECTURE_GUIDE.md) | A specimen representing the measured state and its dependencies |
| 6. Apply in a product screen, if requested | Screen Designer consumes the library and escalates missing pieces | [Role](Design/Screen%20Designer/SCREEN_DESIGNER.md), [disenar-pantalla](skills/disenar-pantalla/SKILL.md) | Screen validation, or a recorded request back to the DS |
| 7. Read back and hand over | The executing agent records result, verification, gaps and next action | [encargar handoff](skills/encargar/SKILL.md) | A recipient can continue without inheriting the whole conversation |

This is a routing example, not a requirement that four agents approve every change. The source guides allow direct work inside each responsibility and consultation when a new decision or ambiguity requires it. Screen application is conditional; it was not an additional deliverable of the historical CTA case.
