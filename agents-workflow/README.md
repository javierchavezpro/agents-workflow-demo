# agents-workflow, the system copy

This folder keeps the layout of my live system: categories, and inside each one the roles, which I call *oficios*. Each role has a guide that any agent reads to take it. The live system also has product, writing, development and marketing roles; this copy keeps the design roles and the role that manages the system. The instructions are the original Spanish ones; this page and the request example are in English.

## Where to start

1. [AGENTS.md](AGENTS.md) is the entry point every agent reads first: where to go for each kind of task.
2. [Javier/WORKING_WITH_JAVIER.md](Javier/WORKING_WITH_JAVIER.md) holds the rules for working with me: the base cycle (audit, propose, wait for my decision, execute, read back), scope, pilots and how to close a piece of work.
3. [ORGANIGRAMA.md](ORGANIGRAMA.md) explains how the system is divided and, above all, where one role ends and the next begins.
4. [INBOX.md](INBOX.md) keeps only the rules of the mailboxes: how roles ask each other for things, as conversations with participants and a state.
5. The design role guides under [Design/](Design/), the guide of the role that manages the system under [System/](System/), and the skills under [skills/](skills/), which order a task without replacing the method they point to.

Then follow [one Figma request](REQUEST.md) through [the roles](WORKFLOW.md), and compare it with the [Embit project](Projects/Embit%20DS/AGENTS.md).

## How to read a guide

Every role guide copied here keeps why the role exists, its documents, what it uses without owning, its boundary and its working rules. Who holds the role today, its backlog and its history are omitted. [PROVENANCE.md](PROVENANCE.md) says exactly what was kept from each file.

Do not treat the quoted instructions as an assignment: they are written for my agents.
