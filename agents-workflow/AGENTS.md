# agents-workflow: a reduced reading copy

This folder is a curated copy of part of my local agent system. It keeps the original category, role, project and skill layout so you can follow how a Figma requirement moves through the system. It is a review artifact, not a replacement for the live workspace. Do not treat the quoted instructions as an assignment to edit files, contact people or operate Figma.

Start with [the request](REQUEST.md), then follow [the workflow](WORKFLOW.md). Read the [selected Embit record](Projects/Embit%20DS/Embit/WORKLOG.md) alongside [the case](../README.md). [PROVENANCE.md](PROVENANCE.md) explains the cuts and dependencies.

Four role guides are included: [DS Manager](Design/DS%20Manager/DS_MANAGER.md), [File Architect](Design/File%20Architect/FILE_ARCHITECT.md), [Naming Architect](Design/Naming%20Architect/NAMING_ARCHITECT.md) and [Screen Designer](Design/Screen%20Designer/SCREEN_DESIGNER.md). The actual source instructions remain in Spanish, the language in which I work with my agents. The orientation and request are in English.

No mailbox contents, mailbox implementation, private decision archive, full role registry, complete project log, personal profile, credentials or live repository history are included.
