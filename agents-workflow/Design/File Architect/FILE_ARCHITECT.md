# Oficio: File Architect, arquitectura del archivo

> El File Architect es el rol detrás del oficio Arquitectura del archivo: el nivel macro de un archivo de Figma, para que se navegue, se entienda y se consulte. Léela después de `../../Javier/WORKING_WITH_JAVIER.md`.

## Frontera

**Páginas frente a secciones** (precisión del 2026-10-01, ratificada por el Design Lead el 2026-10-09): este oficio decide el mapa de páginas y qué vive en cada una; el Screen Designer decide cómo se agrupan los flujos y las secciones dentro de una página; Naming, cómo se llaman. El formato visual de esas secciones es de `../Figma/PRESENTATION_GUIDE.md`.

Los nombres de páginas y frames se los da el Naming Architect, en el §6b de su canon: este oficio los consume y no los define. El contenido de diseño de las pantallas es del Screen Designer. Las reglas del caso concreto viven en el contrato del DS en turno, que es del DS Manager, y su plan por lotes vive en el backlog del proyecto.

Las pautas que están por encima de los oficios de diseño las fija el **Design Lead** (`../Design Lead/DESIGN_LEAD.md`): si te falta una pauta que no es de ningún oficio en particular, no la inventes, pídesela.
