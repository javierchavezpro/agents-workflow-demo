# agents-workflow: how I work with AI agents

I am Javier, a Product Designer. This repository is a reading copy of the system I use to direct AI agents in design, product, writing and development work: who does what, how a request moves between roles, how work is assigned, checked and recorded.

It is **generated** from my live system by a script, not assembled by hand, and it is published in versions. This is version **2026.10**, generated on 2026-10-26.

## The quickest way to read it

The repository is large and its instructions are in Spanish, the language I work in with my agents. **I recommend asking an agent to read it for you**: copy [the review prompt](AGENT_REVIEW_PROMPT.md) into Claude, ChatGPT or a similar tool together with the link to this repository, and ask your own questions afterwards.

## Three routes, if you prefer to read it yourself

- **A real case:** [the Embit case](EMBIT_CASE.md) follows a design-system change in Figma, from the decision to the checks, including a test that needed correction.
- **The system:** [agents-workflow](agents-workflow/README.md) contains the entry rules, how roles divide the work, several role guides and the skills agents use. Start with [one Figma request](agents-workflow/REQUEST.md) and follow [its route through the roles](agents-workflow/WORKFLOW.md).
- **How it was made:** [PROVENANCE](agents-workflow/PROVENANCE.md) lists every copied file and what was cut from it.

## What is not here

This is a selection, not the complete system. Private mailboxes and their history, the projects I work on, personal records, credentials and the full set of methods are left out. Links to files outside this copy are shown as paths, so you can see what a rule refers to without a broken page.
